# sobrelamarcha.github.io

Esta es la página web de Sobre La Marcha Plays donde iré compartiendo poco a poco recursos con la comunidad.

## Trastear la web

Si te gusta el desarrollo web, puedes descargarte este repositorio y probarlo en local. Yo utilizo Zed como editor de código y en una terminal de git bash ejecuto `pnpm dlx live-server` para levantar un servidor local.
